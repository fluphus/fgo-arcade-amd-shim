# FGO Arcade AMD パッチ · 2026.09.22

[中文](README.zh-CN.md) | [English](README.en.md)

**60 FPS 制限は内蔵済みです。**

今回は 60 FPS リミッターを改善し、フレームごとの計時誤差の蓄積を防ぎます。以前の描画修正も含まれます。

## 表示設定

RTSS の `ago.exe` プロファイルなど、ほかのフレームレート制限は無効にし、内蔵の 60 FPS 制限と重複しないようにしてください。

画面のティアリングが発生する場合は、AMD Software: Adrenalin Edition で **Radeon Enhanced Sync（拡張同期）** を有効にしてみてください。通常の垂直同期でフレームレートが低下する場合は、「垂直リフレッシュを待機」を「常にオフ」にし、拡張同期を有効にした状態をお試しください。効果は GPU やドライバーのバージョンによって異なる場合があります。

## インストールと復元

1. アーカイブ全体を展開し、ゲームを終了します。
2. `FgoAmdPatch.exe` を実行し、「参照」で `ago.exe` のあるフォルダー、または `App` を含む親フォルダーを選択します。
3. 「インストール / 更新」を押し、完了後に通常のランチャーから起動します。
4. 元に戻す場合は同じフォルダーを選び、「前回のバックアップを復元」を押します。バックアップ先はゲームフォルダー内の `shim-backups` です。

Windows 10/11 64 ビットと、標準の .NET Framework、Windows PowerShell が必要です。既存ファイルは自動的にバックアップされます。アカウント、サーバー、セーブデータ、ランチャーの設定は維持されます。ゲーム本体は同梱しません。

ソース、採取ツール、テストの手順は [開発者向け説明](source/README.md) を参照してください。`SHA256SUMS.txt` はファイルのチェックサムです。
