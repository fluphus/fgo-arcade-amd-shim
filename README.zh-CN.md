# FGO Arcade AMD 补丁 · 2026.09.15

[English](README.en.md) | [日本語](README.ja.md)

仅测试过 **AMD Radeon RX 7900 XTX**。最新实测中，**PVP 几乎全程保持 60 FPS**，切换从者时短暂降至约 **57 FPS**。不保证其他显卡、PVE 或加载阶段的性能。

**仅支持 1920×1080（1080p）。其他分辨率有已知渲染错误。补丁内置锁定 60 FPS。**

本次更新减少了重复缓冲区读取和绘制状态处理，改善战斗性能。

## 安装与恢复

1. 完整解压压缩包，退出游戏。
2. 运行 `FgoAmdPatch.exe`。
3. 点击「浏览」，选择包含 `ago.exe` 的游戏目录。也可以选择其包含 `App` 文件夹的上一级目录。
4. 点击「安装 / 更新」。看到安装完成后，从原来的启动器进入游戏。

如果需要撤回本次安装，重新打开安装器，选择同一游戏目录，点击「恢复上次备份」。备份保存在游戏目录的 `shim-backups` 文件夹中。

支持 Windows 10 / 11 64 位，使用系统自带的 .NET Framework 和 Windows PowerShell。

安装器会自动备份原文件，保留账号、服务器地址、存档和启动器配置。本包不包含游戏本体。

源码、采样工具和夹具用法见 [开发说明](source/README.md)。`SHA256SUMS.txt` 用于校验文件。
