# FGO Arcade AMD パッチ · 2026.10.06

[中文](README.zh-CN.md) | [English](README.md)

**60 FPS 制限と表示同期を内蔵しています。**

今回の更新では、変換済みシェーダーをメモリにキャッシュしてディスクの再読み込みを減らします。また、シーン切り替え後に動画の共有テクスチャのコピーが失敗する問題を修正し、動画コピー時の CPU 負荷を軽減します。

## 表示設定

- AMD Software の「垂直リフレッシュを待機」は **「アプリケーションで指定しない限りオフ」** にしてください。表示同期はパッチが制御するため、「常にオフ」や「常にオン」に固定しないでください。
- RTSS / MSI Afterburner、AMD のパフォーマンスメトリクス、Steam、Discord、Xbox Game Bar など、すべてのゲーム内オーバーレイを無効にしてください。オーバーレイは表示モードを変え、表示遅延を増やす場合があります。
- RTSS の `ago.exe` プロファイルを含め、ほかのフレームレート制限を無効にしてください。オーバーレイを非表示にするだけでは、フレームレート制限は解除されません。

## インストールと復元

1. アーカイブ全体を展開し、ゲームを終了します。`game-patch` フォルダーは `FgoAmdPatch.exe` と同じ場所に置いてください。
2. `FgoAmdPatch.exe` を実行し、「参照」で `ago.exe` のあるフォルダー、または `App` を含む親フォルダーを選択します。
3. 「インストール / 更新」を押し、完了後に通常のランチャーから起動します。
4. 元に戻す場合は同じフォルダーを選び、「前回のバックアップを復元」を押します。バックアップ先はゲームフォルダー内の `shim-backups` です。

ゲームフォルダーには `opengl32.dll` と `amdcfg/amdOglpSettings.cfg` の両方が必要です。インストーラーは両方をコピーします。設定ファイルがないと、一部のマップで性能が大きく低下する場合があります。

Windows 10/11 64 ビットと、標準の .NET Framework、Windows PowerShell が必要です。既存ファイルは自動的にバックアップされます。アカウント、サーバー、セーブデータ、ランチャーの設定は維持されます。ゲーム本体は同梱しません。

ソース、採取ツール、テストは [リポジトリ](https://github.com/fluphus/fgo-arcade-amd-shim) にあります。使い方は [開発者向け説明](https://github.com/fluphus/fgo-arcade-amd-shim/blob/main/source/README.md) を参照してください。`SHA256SUMS.txt` はファイルのチェックサムです。
