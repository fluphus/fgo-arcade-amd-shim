# FGO Arcade AMD パッチ · 2026.09.16

[中文](README.zh-CN.md) | [English](README.en.md)

動作確認済みの GPU は **AMD Radeon RX 7900 XTX のみ**です。最新の PVP テストでは、**対戦中のほぼ全区間で 60 FPS** を維持し、サーヴァント交代時に一時的に約 **57 FPS** まで低下しました。他の GPU、PVE、ロード画面の性能は保証しません。

**対応解像度は 1920×1080（1080p）のみです。他の解像度では既知の描画不具合があります。60 FPS 制限は内蔵済みです。**

今回の更新では、別のマップで城壁のテクスチャが多色の帯状に伸びて乱れる不具合を修正しました。以前の遠距離攻撃の軌跡、ロンドンの白い閃光、シェーダー復旧の修正も含まれます。

## インストールと復元

1. アーカイブ全体を展開し、ゲームを終了します。
2. `FgoAmdPatch.exe` を実行し、「浏览」（参照）で `ago.exe` のあるフォルダー、または `App` を含む親フォルダーを選択します。
3. 「安装 / 更新」（インストール / 更新）を押し、完了後に通常のランチャーから起動します。
4. 元に戻す場合は同じフォルダーを選び、「恢复上次备份」（直前のバックアップを復元）を押します。バックアップ先はゲームフォルダー内の `shim-backups` です。

Windows 10/11 64 ビットと、標準の .NET Framework、Windows PowerShell が必要です。既存ファイルは自動的にバックアップされます。アカウント、サーバー、セーブデータ、ランチャーの設定は維持されます。ゲーム本体は同梱しません。

ソース、採取ツール、テストの手順は [開発者向け説明](source/README.md) を参照してください。`SHA256SUMS.txt` はファイルのチェックサムです。
